# web-server

Comp 2322 Multi-thread Web Server
=================================

Language: Python
Platform: Windows

How to Run:
1. Make sure you have Python installed.
2. Open the "www" folder included in the project.
3. Place your own image file into the "www" folder.
4. Open the "index.html" file in the "www" folder, and change "StarRail.png" to the name of your own file.
5. Run the server:
   python server.py
6. Open your browser and visit:
   http://127.0.0.1:8080

Supported Features:
- Multi-threaded
- GET and HEAD methods
- 200 / 400 / 403 / 404 / 304 status codes
- Last-Modified & If-Modified-Since
- Keep-alive & close connection
- Log file: server.log
- Serve text and image files
